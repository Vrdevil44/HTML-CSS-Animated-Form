# HTML-CSS Animated Form

An animated contact form built with pure HTML and CSS — designed for a company's organizational appraisal flow.

## What's here

- `index.html` — the form markup
- `style2.css` — animations and styling (no JavaScript, no frameworks)

## Run it

Open `index.html` in any browser. That's it.

## Status

Complete micro-project. A study in CSS-only interaction design.
